# Graph View（0.4.0）验证记录

状态：0.4.0 桌面回归通过，已安全更新批准测试库；移动端图谱仍待真机验收。

## 范围

全局及局部图谱的 Filters / Groups 共用原生查询适配器。Graph view 默认开启；Advanced graph queries 默认关闭，开启后增强 `path:`、`file:`、`tag:` 字面值及原生逻辑组合。后者不改变全库搜索、Find 或 Quick switcher 的语法能力。

- 克隆原生查询及变化的匹配节点，不改输入、token、原始匹配树、文件身份或标签。
- 原生计算负责过滤、分组优先级、颜色、节点资格、局部深度和链接方向；不另建索引或渲染器。
- 否定作用于增强后的条件，不能简单并入原生最终结果。
- 保留标签精确／子级边界，不把全宽斜杠当成标签层级分隔符。
- 正则、属性条件以及 content/line/block/section/task 子树仍走原生；未知接口或超限按单条 filter/group 查询回退，不输出部分展开。
- 开关刷新现有图谱；退役查询和第三方保留的包装器不会重新生效。
- 诊断仅报告入口、类别和固定原因，不包含查询、路径、标签或私有异常详情。

## 实施与验证

- Obsidian 1.13.7 / macOS，独立临时 HOME、profile 和 vault，不控制用户实例。
- 旧 0.3.0 在输入 `發` 后不能检出含 `发` 的图谱节点，原生基线与预期失败已确认（b06f403bd）。
- Python 10 项与 Node 52 项通过（b7a40c236）；锁定字表未变化。
- 单元覆盖原始树不变、开关与持久化、标签边界、大小写、累计预算、未知结构／循环、退役包装器、只读实例隔离、同步扫描及 setter 写入后抛错的完整回退。
- 原生矩阵包含全局／局部、普通／高级、否定／OR／大小写、字段引号、保留子树、颜色顺序、非 BMP 和多码位关系、兼容模式、标签与附件节点、故障恢复、输入原文、打开原文件、设置 UI、重载、核心插件重启及卸载。
- 原生三套回归 b728449cd 退出 0，Graph、设置＋Find／Open file、全库搜索的 `pageErrors` 均为空；浅色／深色／600px 窄窗设置截图和原生全局／局部图谱截图已人工检查。原生控件保留，局部图谱的原生浮动控制面板可能遮住部分节点，不据此宣称所有布局均已验收。
- 除首次输入走纯原生 debounce 外，矩阵用原生 `updateSearch()` 刷新，避免重复相同输入时读到旧队列；仍读取真实原生节点和控制项。

测试脚本修正过大小写不敏感文件系统的夹具冲突、Enter 接受原生补全后插入空格、旧分组队列误满足就绪条件、私有宿主对象跨 Playwright 传输以及导航复用图谱标签页的假设。没有为这些测试假设修改产品语义。

## 限制

仅作者自审，无独立子代理审查。私有接口只在上述桌面版本验证；iOS 图谱尚未实机验收，Android／Windows／Linux 未验收。性能采样只测 10 篇笔记测试库里 1／5／20 组查询的同步设置成本，不能代表大型库、完整 I/O、渲染或移动设备。

主动 LSP 检查 6 个文件返回 0 个错误，其中 1 个确认 clean、5 个 inconclusive；不能宣称全量静态检查全绿。已安装旧生成包的 unused catch 绑定提示已分类，不通过手改生成产物消除。
